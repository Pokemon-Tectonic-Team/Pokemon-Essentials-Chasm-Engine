# Build files

Two scripts here. `Zip-Release.ps1` is intended to be simple and portable, replacing the Chasm Zipper. It should work on any Windows machine without further setup. If you're not comfortable with the command line, you can double click `Zip-Release.bat` to run it.

`Publish-Release` is more complex and requires setup, and handles things like uploading to Google Drive and generating the short links. It's primarily intended for LunaFlare's convenience, but if you want to try using it you can ask her for the details.
